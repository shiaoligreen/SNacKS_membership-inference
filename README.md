- **`milestone1/`** — Milestone 1 written documents
- **`milestone2/`** — Milestone 2 written documents

## Conda environment setup

To set up the necessary packages for running the labs and lecture material, [download the environment file to your computer](https://github.ubc.ca/shiaolig/SNacKS_membership-inference/blob/main/environment.yml) (hit "Raw" and then `Ctrl` + `s` to save it, or copy paste the content). Then create a virtual environment by using `conda` with the environment file you just downloaded:

```         
conda env create --file environment.yml
```

This will set up Python with the correct versions of all required packages.
